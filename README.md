# AWS Student Builder Group — AIUB

Official "Coming Soon" website for the **AWS Student Builder Group at American International University-Bangladesh (AIUB)**.

## Built With

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: Vanilla CSS with AWS SBG Blueprint Grid and Brand Tokens
- **Typography**: Amazon Ember Display, Inter, DM Mono
- **Brand Assets**: Official AWS Student Builder Group lockups

## Getting Started

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production Build

```bash
pnpm build
pnpm start
```
